KEY FILES EXPLAINED:

📄 README.md
   ├─ Overview of both microservices
   ├─ Prerequisites (Docker, Docker Compose)
   ├─ How to start the services
   ├─ API endpoints documentation
   └─ Project structure

🐳 docker-compose.yml
   ├─ Defines two services: car-rental-service and hello-service
   ├─ Port mapping: 8080 -> car-rental, 8081 -> hello
   ├─ Shared network: rental-network (allows inter-service communication)
   └─ Build configuration for each service

🐳 Dockerfile (in both services)
   ├─ Stage 1 (Builder):
   │  ├─ Base image: gradle:8.14-jdk17
   │  ├─ Copies entire project
   │  └─ Runs: gradle clean build -x test
   │
   └─ Stage 2 (Runtime):
      ├─ Base image: eclipse-temurin:17-jre-jammy (lightweight)
      ├─ Copies only the compiled JAR from Stage 1
      ├─ Exposes port 8080 (or 8081 for hello-service)
      └─ Runs: java -jar app.jar

🚀 start.sh
   └─ Bash script with helper commands:
      ├─ ./start.sh up      (Start services)
      ├─ ./start.sh down    (Stop services)
      ├─ ./start.sh logs    (View logs)
      ├─ ./start.sh test    (Test endpoints)
      └─ ./start.sh ps      (Service status)

═══════════════════════════════════════════════════════════════════════════

BUILD & RUN FLOW:

1. START (docker-compose up --build)
   │
   ├─→ Car-Rental-Service
   │   ├─ Build Stage: gradle:8.14-jdk17
   │   │   └─ Compile with Gradle
   │   ├─ Runtime Stage: eclipse-temurin:17-jre-jammy
   │   │   └─ Execute JAR
   │   └─ Listen on Port 8080
   │
   └─→ Hello-Service
       ├─ Build Stage: gradle:8.14-jdk17
       │   └─ Compile with Gradle
       ├─ Runtime Stage: eclipse-temurin:17-jre-jammy
       │   └─ Execute JAR
       └─ Listen on Port 8081

2. COMMUNICATION
   Both services connect to "rental-network"
   → car-rental-service:8080 accessible as "http://car-rental-service:8080"
   → hello-service:8081 accessible as "http://hello-service:8081"

GETTING STARTED:

1. Build and run:
   $ docker-compose up --build

2. Test endpoints:
   $ curl http://localhost:8080/cars
   $ curl http://localhost:8081/hello

3. View logs:
   $ docker-compose logs -f

4. Stop:
   $ docker-compose down
